# 手机端远程控制 · 操作与测试说明

> 适用：Local AI Studio 手机网页（局域网扫码页 + `<你的域名>` 自建中继页，两端控件一致）。
> 三种打开方式：① 扫桌面 📱 面板二维码（同一 WiFi）；② 打开 `https://<你的域名>/s/?d=<token>`；③ 复制链接粘贴到手机浏览器。

## 1. 页面布局（顶部控件位置）

```
┌────────────────────────────────────────────┐
│ [☰ 会话]  [ 项目 ▾ ]              [ ▶ 运行数 ] │  ← 第 1 行：会话抽屉 + 项目切换 + 运行中标记
│ [ 模型 ▾ ]  [ 思考等级 ▾ ]  [ 权限 ▾ ]         │  ← 第 2 行：模型 / 思考等级 / 权限
├────────────────────────────────────────────┤
│  工作区 xxx · 权限 always · N 个会话运行中    │  ← 状态行（自动刷新）
├────────────────────────────────────────────┤
│            （聊天记录 / 气泡）               │
├────────────────────────────────────────────┤
│ 列目录  找BUG  写测试  总结改动  重构建议  这是什么  │  ← 快捷命令（纯文字，点击填入输入框）
│ [ 输入框................................] [发送] │
│  （输入框内打 / 弹出斜杠命令下拉）             │
└────────────────────────────────────────────┘
```

## 2. 三个控件的定位

| 控件 | 位置 | 说明 |
|---|---|---|
| **模型** | 第 2 行第 1 个下拉 | 列出全部模型（当前模型高亮）。显示 `模型名` + 图标（👁视觉 / 🧠推理 / ·本地） |
| **思考等级** | 第 2 行第 2 个下拉 | 只有当前模型是**推理模型**才出现有效选项（如 `none / low / medium / high / xhigh / max`）；当前模型非推理则显示「—」 |
| **权限** | 第 2 行第 3 个下拉 | 总允许 / 询问 / 只读 |

> 💡 想看思考等级的有效选项：把**模型**切到 deepseek 系（如 `deepseek-v4-pro`），思考等级会变成 low/medium/high 等；切到本地 Qwen（非推理）则显示「—」。

## 3. 怎么测（每项操作 + 预期 + 双端同步验证）

### 3.1 模型切换
- **操作**：点「模型」下拉 → 选另一个模型（如 `deepseek-v4-flash`）
- **手机端**：下拉立即切换、显示新模型；顶部列表刷新（当前项高亮随模型变化）
- **电脑端**：顶栏模型下拉**立即同步**换成新模型（经 `model:changed` 事件）
- ✅ 判定：两处模型名一致

### 3.2 思考等级切换
- **前置**：模型切到推理模型（deepseek 系）
- **操作**：点「思考等级」→ 选 `high` 或 `xhigh`
- **手机端**：下拉值变为你选的那档
- **电脑端**：顶栏推理等级下拉**同步**为同一档（经 `model:changed` → 重载模型）
- ✅ 判定：两处思考等级一致；且当前模型非推理时手机端应显示「—」（无有效等级）

### 3.3 权限切换
- **操作**：点「权限」→ 选 `询问`（或 `只读`/`总是允许`）
- **手机端**：下拉显示所选权限；状态行“权限 xxx”同步
- **电脑端**：顶栏权限徽标**立即同步**（⚡总是允许 / 🛡询问 / 🔒只读）（经 `permission:changed` 事件）
- ✅ 判定：手机与电脑权限一致；电脑发消息时按权限拦截（如询问会弹审批）

### 3.4 快捷命令（纯文字）
- **操作**：点「列目录」「找BUG」等文字 → 自动填入输入框（可编辑）
- ✅ 判定：点击后输入框出现对应提示文本，点发送即执行

### 3.5 `/` 斜杠命令下拉
- **操作**：在输入框打 `/` → 弹出命令列表（按后面文字过滤），点一条填入
- ✅ 判定：弹出下拉、点击填入、Esc 关闭

### 3.6 会话与历史
- **操作**：点「☰ 会话」→ 项目会话列表（带 ▶ 运行标记）→ 点一个会话
- **手机端**：加载该会话**完整历史**（含以前的聊天）
- ✅ 判定：旧聊天能看到；正在跑的会话实时补流；▶ 标记随运行状态变化

## 4. 前置：确认链路通（先能再测控件）

```bash
# 服务器是否正常（在你的 VPS 上）
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:9000/s/?d=<token>   # 200=OK，403=token 不对
```

**常见三种状态**：
- 模型下拉显示「**正在连接桌面…**」→ 桌面中继没连上（回查 token 白名单 / 服务器 / 桌面 🌐 状态）
- 模型下拉显示「**暂无模型**」→ 桌面连上了但 `ListModels` 为空
- 模型下拉有列表 → 链路已通，可正常测

## 5. 双端同步清单（改一处的同步验证）

| 在手机端改 | 电脑端同步途径 | 电脑上体现 |
|---|---|---|
| 模型 | `model:changed`（立即） | 顶栏模型下拉 |
| 思考等级 | `model:changed`→重载模型（立即） | 顶栏推理等级下拉 |
| 权限 | `permission:changed`（立即） | 顶栏 ⚡/🛡/🔒 徽标 |

> 反向（电脑改 → 手机更新）依赖手机每 8s 轮询 `state`，模型列表也随连接刷新；实时性略慢，属正常。

## 6. 快速自测步骤（照着点一遍）

1. 手机上打开页面（扫码或地址）
2. 拉到第 2 行：确认「模型」下拉有模型列表（不空）
3. 模型切到 `deepseek-v4-pro` → 手机/电脑模型名都变
4. 思考等级出现 `low/medium/high/xhigh/max` → 选 `high` → 两处都变
5. 「权限」切「询问」→ 手机/电脑权限都变，电脑顶栏变 🛡
6. 输入框打 `/` 弹下拉 → 点「/列目录」填入；或直接点「列目录」文字填入
7. ☰ 会话 → 选旧会话 → 历史完整显示
