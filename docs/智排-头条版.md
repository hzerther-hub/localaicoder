## 三、智排怎么判断"简单还是复杂"？

不是拍脑袋，是一套**有优先级的判定序**（关键词的优先级高于长度，这是很多新手会搞反的点）：

1️⃣ **带图片/文档附件** → 判复杂（本地模型多模态弱，硬上会翻车）
2️⃣ **空文本** → 判简单（多半是工具流程续步）
3️⃣ **含代码块** → 判复杂
4️⃣ **命中强关键词** → 判复杂（设计 / 架构 / 重构 / 调试 / 排查 / 根因 / 优化 / 性能 / 安全 / 为什么 / 如何实现 / 逐步……）
5️⃣ **≥2 个段落** → 判复杂
6️⃣ **超长度阈值**（中文 160 字左右）→ 判复杂
7️⃣ **拿不准的"弱信号区"** → 让本地小模型当裁判，免费问一句"简单还是复杂"

⚠️ 注意第 4 条：**"帮我重构这个模块"只有 8 个字，但"重构"是强关键词，照样走复杂通道。** 按字数只是最后的兜底，不是主判据。

## 四、省钱的核心：一条"级联"管道

这套方案在业界有正经名字——**LLM 级联（Cascading）**，经典论文叫 **FrugalGPT**（2023），LMSYS 也有开源的 **RouteLLM** 框架。思路殊途同归：

```
用户提问
   │
   ▼
【智排判定】─── 简单 ───→ 本地模型（免费）───→ 回答
   │
   复杂/拿不准
   ▼
云端强模型（付费）───→ 回答
```

我的配置里更狠一层：**因为 35B 本地模型够强，"复杂通道"大部分时候也在本地**——只有它都搞不定的，才真正落到 DeepSeek 云端。级联三层几乎全免费，账单不进个位数才怪。

## 五、五条避坑建议（都是踩过的坑）

**1️⃣ 简单通道必须指向"真正在跑"的本地模型。**
配置了没启动的本地服务，每次都会自动切云端兜底——**反而更贵**。哪个模型在跑，就配哪个。

**2️⃣ 长度阈值别太保守。**
中文多是短句，阈值太小会把大量简单任务误判成复杂。先调大观察质量，不行再收紧。

**3️⃣ 强模型能本地就本地。**
能跑 35B 就别客气，把复杂通道也指过去——这是最狠的省钱，代价是要求本机算力（22G 卡的朋友们，你们的硬件够）。

**4️⃣ 兜底模型也要挑。**
没被分级覆盖到的请求走默认模型，默认是付费的就在悄悄花钱。想极致免费就也指本地，想保底智商就留云端。

**5️⃣ "拿不准"时用本地模型仲裁。**
花一次免费调用问"这题简单还是复杂"，避免把复杂任务误判到便宜通道——这笔"保险费"绝对值。

## 六、附：极简 Python 实现（60 行核心逻辑）

只依赖 `requests`，任何 OpenAI 兼容端点都能接（本地 vLLM、llama.cpp、云端全通用）：

```python
import re, time, hashlib, requests

SIMPLE, STRONG, UNSURE = "simple", "strong", "unsure"
KEYWORDS = ("设计", "架构", "重构", "调试", "排查", "根因", "优化",
            "性能", "安全", "为什么", "如何实现", "逐步")
EN = re.compile(r"\b(design|refactor|debug|root cause|optimi[sz]e|how to)\b", re.I)

def classify(text: str, has_img=False) -> str:
    if has_img:                 return STRONG   # 附件：强模型
    if not text.strip():        return SIMPLE   # 空文本：便宜侧
    if "```" in text:           return STRONG   # 代码块
    if EN.search(text) or any(k in text for k in KEYWORDS):
                                return STRONG   # 强关键词
    zh = any("\u4e00" <= c <= "\u9fff" for c in text)
    n = len(text)
    if zh and n > 56:           return STRONG   # 中文阈值（词数28×2）
    if n > 160:                 return STRONG   # 长度兜底
    if n > 120 or (not zh and len(text.split()) > 21):
                                return UNSURE   # 弱信号区 → 仲裁
    return SIMPLE

class SmartRouter:
    """simple/strong/arb 三槽位：(endpoint, api_key, model)"""
    def __init__(self, simple, strong, arb=None):
        self.slots = {"simple": simple, "strong": strong, "arb": arb or simple}
        self.cache = {}

    def _chat(self, slot, prompt, text, timeout=8):
        url, key, model = slot
        try:
            r = requests.post(f"{url.rstrip('/')}/chat/completions",
                headers={"Authorization": f"Bearer {key}"},
                json={"model": model, "max_tokens": 512,
                      "messages": [{"role": "user", "content": prompt + "\n" + text}]},
                timeout=timeout)
            return r.json()["choices"][0]["message"]["content"]
        except Exception:
            return ""   # 一切失败归 simple

    def arbitrate(self, text):
        key = hashlib.sha1(text.encode()).hexdigest()
        if key in self.cache: return self.cache[key]
        ans = self._chat(self.slots["arb"], "这问题简单还是复杂？只答：简单/复杂", text)
        d = STRONG if "复杂" in ans else SIMPLE
        self.cache[key] = d
        return d

    def resolve(self, text, has_img=False):
        d = classify(text, has_img)
        if d == UNSURE: d = self.arbitrate(text)
        return self.slots["strong"][2] if d == STRONG else self.slots["simple"][2]

# 用法：本地免费当简单+仲裁通道，云端只接重活
LOCAL = ("http://127.0.0.1:8099/v1", "local-noauth", "你的本地模型名")
CLOUD = ("https://api.deepseek.com", "你的KEY", "deepseek-chat")
router = SmartRouter(LOCAL, CLOUD, arb=LOCAL)
print(router.resolve("这句话什么意思？"))   # simple → 本地免费
print(router.resolve("帮我重构这个模块"))   # strong → 云端强模型
```

三个关键纪律，比代码本身更重要：

✅ **一切失败归 simple** —— 仲裁超时、端点失联都走便宜侧，路由器绝不能成为新故障点；
✅ **仲裁结果按文本哈希缓存** —— 同样的问题不二次花判定成本；
✅ **simple 槽缺位自动升级 strong** —— 宁可保守，不丢路由。
